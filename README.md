# Лабораторная работа № 5: Разработка базового SPA на React

## Описание страниц и компонентов

### 1. Навигационная панель (TabBar)
Расположена в нижней части экрана и содержит 4 пункта:
* **Лента** (`/feed`) — просмотр видео типов производств в полноэкранном режиме.
* **Добавление** (заглушка) — в данной лабораторной работе страница не открывается, подготовлена для будущих релизов.
* **Плитка / Каталог** (`/`) — главная страница со списком типов производств.
* **Вход** (заглушка) — страница авторизации, зарезервирована для следующих лабораторных работ.

### 2. Страница плитки
Главная страница приложения для обзора всех доступных типов производств.
* **Поля и элементы:**
  * **Фильтр-слайдер («Норма выхода»):** Два сопряженных ползунка для выбора минимального и максимального значения (0–200 шт).
  * **Текстовый вывод диапазона:** Отображает текущие выбранные значения.
  * **Кнопка «НАЙТИ»:** Кнопка отправки формы (`React-Bootstrap`), по нажатию которой выполняется фильтрация списка карточек.
* **Карточка типов производстви:**
  * Содержит изображение (`default-image.jpg`), название (`craft_title`), норму производства, количество лайков и условную кнопку «Удалить» для созданных типов производств.
  * Клик по карточке открывает её в Ленте.

### 3. Страница ленты
Полноэкранный просмотр типов производстви в стиле вертикальной ленты.
* **Поля и элементы:**
  * **Медиаплеер:** Фоновое видео (`default-video.mp4`).
  * **Заголовок и лайки:** Название типов производстви и счетчик лайков.
  * **Кнопка «Далее» (`🡳`):** Переключает на следующую типов производству в списке (с циклическим возвратом).
  * **Блок описания:** Текст типов производстви с выравниванием по левому краю и кнопкой раскрытия «Ещё» / «Свернуть».
  * **Параметры:** Норма производства и количество брака.
