# Лабораторная работа № 5: Разработка базового SPA на React

## Структура приложения и описание четырех страниц

### 1. Навигационная панель (TabBar)
Расположена в нижней части экрана и содержит 4 пункта:
* **Лента** — просмотр видео типов производств в полноэкранном режиме.
* **Добавление** — страница создания нового типа производства. После ДАЛЕЕ хранит черновик до опубликования
* **Плиткаг** — главная страница со списком типов производств.
* **Вход** — страница авторизации
---

### 2. Страница «Плитка»
Главная страница приложения, доступная по корневому маршруту (`/`), предназначенная для общего обзора и поиска доступных типов производств и услуг.**Назначение:** Вывод списка всех опубликованных услуг в виде сетки карточек с возможностью фильтрации по диапазону нормы выхода.
* **Элементы интерфейса и поля:**
  * **Фильтр-слайдер («Норма выхода»):** Два ползунка для выбора минимального и максимального значения производительности.
  * **Текстовый вывод диапазона:** Информационная строка, отображающая текущие выбранные пользователем числовые границы.
  * **Кнопка «НАЙТИ»:** Кнопка отправки формы, по нажатию которой выполняется клиентская фильтрация списка карточек.
* **Карточка услуги (компонент):**
  * **Поля:** Название услуги (`craft_title`), норма производства (`production_output_rate`), счетчик лайков (`likes_count`).
  * **Медиа:** Изображение услуги с автоматическим fallback на `/img/default-image.jpg`, если поле пустое.
  * **Интерактив:** Клик по карточке осуществляет плавный переход на страницу «Лента» (`/feed/{id}`) для выбранного элемента.
  * **Дополнительно:** Кнопка «Удалить» для логического удаления своих записей у создателя.

---

### 3. Страница «Лента»
Полноэкранный просмотр услуг в вертикальном формате (маршрут `/feed`). **Назначение:** Погружение в детали конкретной услуги с возможностью непрерывного листания всего каталога.
* **Элементы интерфейса и поля:**
  * **Медиаплеер:** Фоновое видео услуги (`video_url`) с поддержкой автоматического воспроизведения, циклического повтора и отключенного звука. При отсутствии видео автоматически подставляется дефолтный ролик (`/img/default-video.mp4`).
  * **Информационный оверлей:** Название услуги, счетчик лайков в виде иконки сердца.
  * **Кнопка «Следующий» (`🡳`):** Интерактивная стрелочка вниз, которая переключает отображение на следующую услугу в списке (с циклическим возвратом к началу).
  * **Блок описания:** Текст услуги с поддержкой многострочного отображения и кнопкой развертывания/сворачивания («Ещё» / «Свернуть»).
  * **Параметры:** Числовые значения нормы производства и количества образовавшегося брака.

---

### 4. Страница «Добавление» / Черновик
Интерфейс для создателей контента (доступен по маршруту `/production_types/draft`). **Назначение:** Формирование, редактирование и публикация новых типов производств. *(Примечание: В рамках текущей 5-й лабораторной работы страница выполняет роль визуальной заглушки и пока заблокирована для открытия).*
* **Элементы интерфейса и поля:**
  * **Загрузка медиа:** Кнопки «ВЫБРАТЬ ИЗОБРАЖЕНИЕ» и «ВЫБРАТЬ ВИДЕО» с блоками предпросмотра загруженных файлов.
  * **Базовая информация (Шаг 1):** Текстовое поле ввода названия («Тип производства») и кнопка «ДАЛЕЕ» для сохранения базового черновика в БД и перехода к деталям.
  * **Детальная информация (Шаг 2):** Все предыдущие поля, многострочное поле ввода «Описание», а также числовые поля «Норма выхода продукции (шт)» и «Количество отходов/брака (кг)».
  * **Кнопка «ОПУБЛИКОВАТЬ»:** Отправка полностью заполненной формы на сервер для смены статуса черновика на опубликованный.

---

### 5. Страница «Вход» / Аутентификация
Раздел авторизации и регистрации пользователей. **Назначение:** Получение доступа к интерфейсу создателя (добавление типов производств, лайки). *(Примечание: В рамках текущей 5-й лабораторной работы страница выполняет роль визуальной заглушки и пока заблокирована для открытия).*
* **Элементы интерфейса и поля:**
  * **Форма ввода данных:** Текстовые поля для ввода имени пользователя (`username`) и пароля (`password`).
  * **Кнопка «Войти»:** Для отправки учетных данных на бэкенд и получения сессионной куки (переход в режим создателя).
  * **Кнопка «Зарегистрироваться»:** Для создания новой учетной записи в базе данных.
